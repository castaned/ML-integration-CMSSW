# Practical Machine Learning in HEP: Yuca y CERN Open Data

El curso Yuca Open Data y Practical Machine Learning in HEP son **el mismo curso**. La portada y el programa unificados están en [Inicio del curso](../practical-ml-hep/index.md).

## Orden de trabajo

1. [Activar la cuenta y 2FA por SSH](00_acceso.md), una sola vez.
2. [Preparar el repositorio y entorno](01_entorno.md), en una etapa posterior.
3. [Revisar los datos abiertos y NanoAOD](02_datos.md).
4. [Seleccionar eventos, reconstruir observables y clasificar Higgs frente a ZZ](../practical-ml-hep/higgs.md).
5. [Estudiar anomalías con el autoencoder CMS](../practical-ml-hep/autoencoder.md).
6. [Modificar el análisis y registrar experimentos](../practical-ml-hep/experiments.md).

Las páginas anteriores de procesamiento ROOT/HDF5, clasificador y autoencoder del framework se conservan como referencias dentro del curso. El programa presencial ocupa miércoles tres horas y jueves una hora.
