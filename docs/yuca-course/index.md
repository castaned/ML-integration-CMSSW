# Practical Machine Learning in HEP: Yuca y CERN Open Data

El curso Yuca Open Data y Practical Machine Learning in HEP son **el mismo curso**. La portada y el programa unificados están en [Inicio del curso](../practical-ml-hep/index.md).

## Orden de trabajo

1. [Configurar el acceso, repositorio y entorno](01_entorno.md).
2. [Revisar los datos abiertos y NanoAOD](02_datos.md).
3. [Seleccionar eventos, reconstruir observables y clasificar Higgs frente a ZZ](../practical-ml-hep/higgs.md).
4. [Estudiar anomalías con el autoencoder CMS](../practical-ml-hep/autoencoder.md).
5. [Modificar el análisis y registrar experimentos](../practical-ml-hep/experiments.md).

Las páginas anteriores de procesamiento ROOT/HDF5, clasificador y autoencoder del framework se conservan como referencias dentro del curso. El programa presencial ocupa miércoles tres horas y jueves una hora.
